# Share SuperGallery

## Short introduction

SuperGallery turns a NAS folder library into a searchable gallery: find photos by meaning, group familiar faces, search text in documents and review duplicates. Core search runs locally. Built for UGREEN and available as a Docker app.

Repository: https://github.com/SaiKrishnaDaddala/SuperGallery
Install: https://github.com/SaiKrishnaDaddala/SuperGallery#quick-start
Questions: https://github.com/SaiKrishnaDaddala/SuperGallery/discussions

## LinkedIn launch draft

I built SuperGallery to make the photos and files on my NAS easier to find and organize.

Instead of remembering a filename, I can search for a scene such as “people cycling”. SuperGallery also groups faces, finds text in images and documents, and helps review duplicate files. Core AI search runs on the NAS.

It is open source, works with Docker, and includes setup guides, optional feature switches and authenticator verification. The default library mount is read-only, so you can try browsing and search before enabling file changes.

If you have a UGREEN NAS or another Docker host, I would love feedback on the installation experience and the features that would help you most.

Try it: https://github.com/SaiKrishnaDaddala/SuperGallery

## A useful launch sequence

1. Test the documented install on a clean instance and record a short walkthrough with synthetic media: install, scan, search, duplicate review.
2. Share the walkthrough and repository link with communities where self-promotion is allowed; disclose that you are the creator.
3. Invite concrete feedback on setup and search quality. Track reproducible bugs in Issues and setup questions in Discussions.
4. Publish release notes with fixes, migration instructions and known limits. Respond to early reports before adding more features.

Avoid promises of perfect recognition or guaranteed storage savings. Local search needs indexing, face grouping can be wrong, and users should keep independent backups. Never use real face crops, private media or device credentials in promotional material.
